# 退休规划测算器（公开静态站）

纯静态单页网站：`index.html` + `css/style.css` + `js/`。无构建步骤、无后端，
所有计算在浏览器本地完成，数据不离开浏览器。图表库 Chart.js 走 CDN。

## 打开方式

- 直接双击 `index.html`（file://）即可用；
- 或 `cd retire-plan-site && python3 -m http.server` 后访问 http://localhost:8000。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 页面结构、全部输入项、结果区、免责声明 |
| `css/style.css` | 样式 |
| `js/tax.js` | 联邦税引擎（MFJ 口径，移植自已验证的 `tax_model.py`）+ 州税模块（CA/NV，可扩展）+ Section 121 卖房税务 |
| `js/engine.js` | 累积期、退休后逐年账本、求解器、敏感性分析 |
| `js/app.js` | UI 绑定、图表与表格渲染 |

## 功能

- **哪年能退休求解器**：退休年龄从 max(当前年龄,50) 扫到 75 岁，三策略各跑一遍，给出最早可行年龄 + 各年龄→期末净资产表。
- **退休后逐年账本**：普通收入/资本利得/AGI/扣除/应税收入/联邦税/NIIT/州税/IRMAA/Roth 转换/RMD/社安金/三类账户余额。
- **Roth 策略对比**：A 不转换 / B 填满 12% 档 / C 填满 22% 档（转到本人 75 岁止）。
- **加州 vs 内华达对比**：整套规划在两种方案下各跑一遍，并排对比终身税、期末净资产、逐年税差；搬家成本计入退休当年。
- **住房安排（可选）**：卖房税务（Section 121 联合申报 $500K 免税额、应税 gain 按 LTCG 计税并计入当年 MAGI 影响 IRMAA/Roth 空间）、downsize 换房差额进账。
- **敏感性分析**：支出 ±20%、回报 ±1% 对最早退休年龄的影响。

## 税务口径（MFJ 写死）

- 联邦：2026 年税表（IRS Rev. Proc. 2025-32）为基准按通胀指数化；标准扣除含 65+ 附加；
  2025–2028 每位 65+ 另有 $6,000 老年扣除（MAGI 超 $150K 按 6% 递减）。
- IRMAA 阈值、NIIT $250K、社安金计税阈值（$32K/$44K）法定不指数化；IRMAA 两年回溯、65 岁起按人征收。
- RMD 75 岁起，按夫妻各自税前余额分别计算。
- 加州（简化）：CA 应税收入 = 联邦 AGI − 应税社安金 − CA 标准扣除（2026 MFJ $11,412）；
  9 档累进 1%–12.3%（2026 Schedule Y）；个人免税额 credit $306（联合）+ 每位 65+ $153；
  CA 应税收入超 $1M 部分另加 1%（BHSA）；资本利得按普通收入计税；税率表/扣除/credit 按通胀指数化，$1M 门槛冻结。
- 内华达：无州个人所得税。

- `node --check` 三个 JS 文件通过。

  的 fed/agi/ded/ti/tss/sb/ord_all 与 Python 输出**小数点后两位完全一致**；`irmaa_annual`、`rmd_for`、
  `senior_bonus`、`bracket_tax` 一致。
- 卖房：MFJ $600K gain + 满足 2 年自住 → 应税 $100K；不满足 → 应税 $600K；$352K gain → $0。

- 求解器：慷慨储蓄组合 → 最早 50 岁；极低储蓄组合 → 返回 null，前端显示"在 75 岁前无法达到目标"及建议。
- Node DOM-stub 端到端：默认输入下完整跑通（headline 57 岁、求解表 27 行、策略卡 3 张、对比区显示、明细表 39 行、敏感性 6 行），无异常。
